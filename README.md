此 **Carsales 汽车列表数据集样本**包含 **1,000 条记录**，通过 **Bright Data API** 提取。

## 数据字段

| 字段名称 | 说明 |
|------------|-------------|
| `car_id` | 每条汽车列表的唯一标识符。 |
| `url` | 汽车详细列表页面的直接 URL。 |
| `manufacturer` | 汽车制造商的名称。 |
| `model` | 汽车的具体型号名称。 |
| `badge` | 汽车型号的详细版本或配置。 |
| `year` | 汽车的生产年份。 |
| `price` | 汽车的标价。 |
| `currency` | 汽车标价所使用的货币。 |
| `main_image` | 汽车列表主图的 URL。 |
| `location` | 汽车所在的地理位置。 |
| `fuel_type` | 汽车使用的燃料类型（例如汽油、柴油）。 |
| `seller_type` | 卖家类型，例如经销商或个人卖家。 |
| `seller_id` | 汽车卖家的唯一标识符。 |
| `images` | 汽车其他图片的 URL。 |
| `vehicle_description` | 车辆功能和车况的说明。 |
| `powerplant_type` | 为汽车提供动力的发动机或电动机类型。 |
| `cost_to_insure` | 汽车的预估保险费用。 |
| `engine` | 汽车的发动机规格。 |
| `dealer_info` | 汽车经销商的相关信息。 |
| `year_num` | 以数字表示的汽车生产年份。 |


## 使用场景

### 1. 市场价格分析
使用此数据集分析不同汽车型号和制造商的价格趋势。这可以帮助企业了解市场动态并制定具有竞争力的价格。

### 2. 汽车市场研究
研究人员可以利用此数据集研究汽车行业趋势、消费者偏好以及各种汽车型号随时间变化的受欢迎程度，从而辅助战略决策。

### 3. 保险费用估算
保险公司可以使用这些数据，根据汽车型号、年份和动力系统类型等属性估算保险费用，从而根据客户需求定制保险产品。
